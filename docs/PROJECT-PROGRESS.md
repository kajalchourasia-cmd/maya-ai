## Provider evidence

xAI `grok-4.6` was measured on 8 frozen fictional cases under user-authorized cost limits: 6/8 completed, 4/8 passed Stage 8 display, 2/2 urgent/clarification cases used zero model calls, cost $0.020862, median 4299.24 ms and p95 5926.12 ms. Medication and final plan-composition calls failed closed. This is insufficient for selection.

OpenAI `gpt-5.4-mini` key/model-list access succeeded, but the six called cases failed closed and a redacted direct diagnostic returned HTTP 429/no credits. The two no-call safety cases behaved correctly. Adding credits in the console has not yet produced a successful inference call in this environment.

## Mode and write boundaries

Demo Mode accepts only allowlisted fictional workspaces and the in-memory committer. Personal Mode requires authenticated database-derived state, public Supabase configuration and an explicitly configured non-fixture provider. Agents/models cannot write durable state; all facts, plans, tasks and simulated-review transitions pass through Stage 10. Real uploads and external reviewer/notification transmission are unavailable.
