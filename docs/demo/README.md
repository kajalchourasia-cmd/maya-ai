## Recording and evaluation boundaries

This is the final action-led v2 recording. It contains actual UI navigation, plan submission and
message/reply interactions, using synthetic onboarding details. No personal medical document is uploaded.
Long processing waits are shortened in the edit; it is not a performance or latency benchmark.

The recorded plan and five replies returned successful HTTP responses. The applicable RAG routes
recorded retrieval, generation receipts, citations and retained context. The plan contained seven days.
Urgent and secret requests took their dedicated routes. These are recorded-run results, not a new test run.

Answer quality is not the same as transport success. In this recording, the first meal request returned
a general nutrient overview instead of a detailed meal list. The vegan follow-up supplied food groups,
not recipes. Neither was replaced with a scripted answer. More specific answers remain improvement work.
Plans are suggestions, not calculated nutritionally complete menus. Source drawers remain closed in the recording.

The older September 13 video and earlier montage are not the final linked demo. Raw captures,
provider ledgers and debug logs remain private and are not included here.
