# Maya AI naming guide

**Canonical project name:** Maya AI  
**Companion name:** Maya  
**Conversational experience:** Ask Maya  
**Original capstone team:** Group 62

**Independent continuation maintainer:** Kajal

**Current repository:** https://github.com/kajalchourasia-cmd/maya-ai

Use **Maya AI** when referring to the complete product, architecture, repository, evaluation system, or case study. Use **Maya** when speaking directly about the companion. Use **Ask Maya** for the chat interface or conversational interaction.

The earlier product name **Nestline** and assistant name **Compass** are retired from current public-facing copy. Historical filenames, source identifiers, branch references, commit messages, generated artifacts, and old verification reports may preserve those terms so links and audit evidence remain reproducible. Their presence is historical metadata, not the current product identity.

## Release integration note

The independent continuation starts with a fresh snapshot commit under Kajal's GitHub identity.
Earlier commit history is preserved in the original repository and a private backup, not imported
into the new main branch. Historical Group 62 artifacts, review records and source notices remain;
the fresh history does not change source-use permissions. See [repository transition](MAYA-REPOSITORY-TRANSITION.md).

The current React UI, README and public-facing documentation use Maya AI and Ask Maya. The historical Stage 9 verifier and recorded safety specification retain their exact audited bytes; persisted identifiers and source-use records are not rewritten for branding. The integration review board records these exceptions.
